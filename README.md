# Activité 2 — Balance et équations

Activité interactive autonome pour GitHub Pages.

## Mise en ligne rapide

1. Créer un dépôt GitHub public, par exemple `activite2-balance`.
2. Cliquer sur **Add file > Upload files**.
3. Déposer les fichiers `index.html`, `.nojekyll`, `README.md` et `code_iframe_ENT.txt`.
4. Cliquer sur **Commit changes**.
5. Aller dans **Settings > Pages**.
6. Choisir **Deploy from a branch**, branche `main`, dossier `/root`.
7. Récupérer le lien GitHub Pages.

## Dans l'ENT

Ajouter une ressource de type lien web vers l'URL GitHub Pages.
Si l'ENT accepte les intégrations iframe, utiliser le code fourni dans `code_iframe_ENT.txt`.

## Récupération des travaux élèves

Les réponses sont enregistrées localement dans le navigateur de l'élève.
L'élève doit cliquer sur **Télécharger mes réponses**, puis déposer le fichier `.txt` dans l'ENT.

## Notation corrigée

Les expressions affichées sur la balance utilisent maintenant une écriture mathématique plus propre : `6 pommes + 10` au lieu de `6 pomme + 10 +1`. Les constantes `+1` sont regroupées en nombres.
